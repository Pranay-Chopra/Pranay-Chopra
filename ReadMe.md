# 💫 About Me:
I’m Pranay Chopra, a CS student at LNMIIT. I build practical, Linux-first software — from CluMS, a GTK3 club-management tool used by my school, to FORCE-Talk, a production-ready video+chat platform built for FORCE-Fest. I also design fast, polished websites (mostly private) and work on Arch Linux tooling as I prepare to contribute upstream.
